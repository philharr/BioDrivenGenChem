# Biologically-driven generative chemistry: Table 1

This repository contains Table 1 for the review **Biologically-driven generative chemistry: using biological data to guide *de novo* drug design**.

By Philip John Harrison and Rocío Mercado.

- [View the CSV table](data/BioDrivenGenChem_Table1.csv)
- Open the searchable/filterable version via GitHub Pages once Pages is enabled for the `docs/` folder.

The CSV file in `data/` is the data source. The HTML page in `docs/index.html` loads this CSV and provides a more convenient searchable, filterable, and sortable version.

## Note

The model names enclosed in square brackets are not the official names, but those that we used in our review paper for convenience.
